DUARTE CLAN V68 — STORY LIKE + MESSAGE
1. Run V68_STORY_LIKES_MESSAGES_SETUP.sql once in Supabase SQL Editor.
2. Deploy the files in this package.
3. Open a Family Story on desktop or mobile.
4. Members can Like/Unlike and Send message to the story owner.
5. The story owner does not see a Send message button on their own story.
